# Changelog

## 0.2.4+7 — 2026-08-26

- Added the Pinata/IPFS model mirror to improve download reliability.
- Restricted model downloads to approved HTTPS hosts and validated redirects.
- Added resumable, concurrent downloads with provider failover and integrity checks.
- Improved Linux/Crostini compatibility by building the required native LlamaDart runtime locally.
- Improved scanner responsiveness, progress update throttling, and mobile layout behavior.
- Updated CI workflows for analysis and multi-platform release builds.
- Added release guidance for Android signing and Google Play App Signing.
